# 视界 MPV · 详细功能介绍

> 以下文字原稿标注适用 v1.30，供了解功能之用；下载包为 v1.31。

视界 mpv · 应用功能介绍（详细版）
适用版本　视界 mpv v1.30｜Windows｜基于 mpv 0.42.0

视界 mpv 是一款基于 mpv 的 Windows 影音播放器，适合把电脑接到电视、投影或家庭影院系统使用。坐在沙发上，用遥控器翻海报、选集、续看和换台。回到电脑前，也可以用鼠标拖放文件、看进度预览、调字幕和画质。

它把本地片库、Emby、蓝光原盘、电视直播和音乐放进一个应用。喜欢研究影音效果的用户，还能为不同片源设置 HDR、杜比视界和刷新率，按家里的扬声器布局渲染全景声，并在中文信息面板里核对当前真正输出的信号。

01　客厅大屏首页与动态桌面

打开应用，底部卡片可以直达海报墙、电视直播、打开文件、近期播放和菜单设置。鼠标点击或遥控器方向键加确定都可以进入。启动时可选择打开应用首页、海报墙或电视直播，也可以在动态桌面和经典首页之间切换。

背景主题提供城市、自然、太空、水下等场景。网络视频按需读取并缓存，也可以用自己的照片和视频。喜欢的背景可以收藏，播放时可选单段循环、顺序轮播或随机轮播。时钟、日期、农历和天气可按需要显示。屏保支持海报墙剧照和动态视频，闲置多久启动由用户决定。

在「卡片中心」可以预览不同图案，调整入口的样式、顺序、显隐、名称和动作。除了常用菜单，还可以把最近观看或最新入库的一部电影、剧集、某个收藏频道或最近观看的频道放到首页，也能添加文件夹、文件、网址和自定义 mpv 指令。

入口　右键 → 外观设计 → 首页与动态桌面／背景主题库／卡片中心／屏保

02　海报墙与本地片库

添加电影、剧集或音乐目录后，可以在大屏上浏览海报、剧照、简介和演职员资料。首页集中展示「正在观看」和「最新添加」。选择一部电影可进详情页，选择剧集可按季、按集浏览。正在观看的影片可续播，也可从头播放。停止从详情页发起的播放后，可以回到原详情页继续挑片。

海报墙的首页、合集页和详情页可分别调整样式。首页有影院、海报、小组件、列表等布局，合集可选封面或网格等布局。电影和剧集可以设置细分类，把电视剧、纪录片、动漫等分开。筛选支持年份、标签、国家或地区、影片或音轨语言，具体结果取决于片库已提供的资料。分类可以改名、排序和调整显隐，筛选项可以按需要调整显示与排列顺序。

本地片库可以读取已有的 NFO 资料与封面。需要补充资料时，可在设置中心配置刮削服务，获取片名、海报、简介和演职员信息。资料不完整的收藏也可以开启文件夹浏览，按原目录找视频或音乐。常看的影片可收藏，打开分类或从详情返回时可保留浏览位置。

入口　按 W 打开海报墙。用 F3 搜索。在海报墙右键可切换样式或打开电脑设置中心。

03　Emby 媒体库与观看进度

在电脑设置中心填写 Emby 服务器地址，用用户名和密码连接，也可按需求选择 API Key。接入后，可在海报墙浏览电影、剧集和音乐。分类可以绑定到指定 Emby 媒体库。启用相应同步后，观看进度、已看状态和收藏可与所连接的 Emby 账号同步。

普通媒体可直接从 Emby 串流，也可通过路径对应优先读取电脑能访问的磁盘或共享目录。原盘文件夹能否直接播放正片，取决于 Emby 能否提供对应媒体流。Emby 能提供支持按块读取的原始 ISO 媒体流时，可以通过网络读取蓝光 ISO。需要完整访问光盘结构和菜单时，建议配置共享路径，让播放器读取原盘文件或文件夹。

大型片库采用分批读取和海报缓存。国家、地区、语言等筛选可按需建立索引，浏览时按需载入后续内容。首次载入时间取决于服务器响应、网络和片库资料。

入口　电脑设置中心 → Emby／片库分类

04　文件、网址、近期播放与书签

可把视频或文件夹拖到播放器窗口，使用内置文件浏览器选片，或打开适用的媒体网址。较慢的文件和网络播放源会显示开播进度，等首帧准备好后进入播放。等待中可以按返回键或点「取消打开」。

内置浏览器可以收藏常用文件夹，打开时可定位到上次位置或指定目录。近期播放会列出已播放的文件及进度，点开可继续观看。也可在影片的某个时间点加书签，便于回看精彩片段。

入口　O 打开文件，Ctrl+O 打开 Windows 文件选择，H 查看近期播放，N 查看书签。

05　播放控制、进度预览与追剧

播放电影或剧集时，遥控器按确定唤出底栏，左右选择按钮，再按确定执行。按上键进入进度预览，左右查看不同位置的缩略图，确定后跳转。用鼠标时，把指针移到进度条上也可预览。按默认设置，返回键先取消预览或收起底栏，再按返回可退出播放。鼠标单击、双击、Esc 和常用按键都可按习惯设置。

追剧可以保存本季的音轨和字幕偏好，下一集应用能匹配的选轨。开启自动连播后，可以设置下一集倒计时，届时选择立即播放或取消本次连播。片头和片尾可用同一个开关控制自动跳过，可手动标记、在时间轴上调整，也可启动后台检测，检测结果取决于片源。直接打开普通本地视频时，也可以在底栏控制同文件夹视频是否连播。

入口　右键 → 播放 → 追剧／片头片尾。右键 → 外观设计 → 鼠标与遥控操作／自定义快捷键／底部控制栏按钮。

06　蓝光、DVD 与原盘菜单

支持打开蓝光 ISO 和 BDMV 目录，也支持 DVD ISO 和 VIDEO_TS 目录。可以按设置直入正片，或在兼容的原盘上打开光盘菜单，像使用实体播放机一样选择播放、章节、语言和字幕。可用时，电影详情页也可以提供单独的「蓝光菜单」按钮。

蓝光菜单包括 HDMV 和需要 Java 的 BD-J。随包提供 BD-J 所需的 Java 运行环境。不同原盘的菜单、区码和加密情况会影响能否进入菜单。可在播放器的「光盘」设置里选择标题、版本，也可尝试按指定区码重新打开蓝光菜单。加密原盘需要本机已有可用的解密配置。

入口　右键 → 视频 → 光盘。播放原盘时可按 Ctrl+M 尝试打开光盘主菜单。

07　杜比视界、HDR 与显示输出

在兼容的 NVIDIA HDMI 输出链路上，可把杜比视界画面和相关动态元数据送给支持标准杜比视界的电视，由电视进行色调映射。支持 Profile 5、8.1、8.6，以及符合条件的 Profile 7 双层片源。Profile 7 可以合成基础层和增强层，适用片源包括单轨封装和受支持的双轨原盘。根据需求或设备能力，也可由 mpv 将杜比视界映射为 HDR 或 SDR。

杜比视界、HDR10 和 SDR 可分别设置处理方案。HDR10 可输出 HDR、映射为 SDR，或尝试转换为杜比视界。SDR 可以原样播放、用 mpv 转 HDR，也可以在支持的 NVIDIA RTX 显卡和 D3D11 硬解环境下使用 RTX HDR。通过 RTX HDR 再转杜比视界属于试验选项。转换后的信号与播放原生杜比视界片源是两种不同的处理方案。

「视界原生」和「CB1 兼容」是可选的杜比处理引擎。CB1 为实验模式，提供电视处理、转 HDR10、转 SDR 和手动指定显示峰值与黑位等选项。可用性取决于系统和图形环境，CPU 解码也仍需可用的 D3D11 图形环境。另有 L5 活动区域开关、杜比界面基准亮度和部分内容映射选项，可按显示设备调整。

分辨率与刷新率可保持当前设置、跟随片源或选用设备支持的固定档位。分辨率跟随影片时，可以让电脑把 1080p 放大至 4K 输出，也可以输出 1080p 交给电视升频。刷新率可匹配 23.976、24、50、59.94、60 Hz 等实际支持的档位。默认退出播放器时恢复原显示模式，便于连续观看同类影片时保留分辨率与刷新率。也可设为停止播放时恢复或持续保留。首页、海报墙和直播主页可分别设为跟随上次播放、自动、固定 SDR、固定 HDR 或实验性的杜比视界输出。

入口　按 K 选择各类片源的输出方案。分辨率、刷新率和恢复时机可在右键「视频」菜单调整。播放时按 I 核对实际输出。

08　画质调校、反交错与字幕外观

「画质与视频增强」提供亮度、对比度、伽马、色温、饱和度、去色带、缩放算法和显示同步等选项。隔行电视、老录像和部分 DVD 可选择自动或强制反交错，减少运动边缘的梳齿。部分锐化、降噪和色温选项用于 SDR 输出，也支持按需选择 ICC 或 LUT 校色文件。

音轨和字幕在独立的选择菜单中显示。音轨可查看语言、编码和声道，支持跟随片源默认标记，也可设置语言偏好。字幕可自动选择简体、繁体或双语，也可手动加载外挂字幕。字幕外观提供亮度、透明度和颜色等调节，可让字幕更适合夜间观影。在线字幕可按片名或集数查找，选中的字幕可下载后加载。配置来源后，本地片库也可启用自动补字幕和后续剧集预取。

入口　右键 → 视频 → 画质与视频增强。A 选音轨，J 选字幕，Ctrl+Shift+S 查找在线字幕。

09　全景声渲染与功放输出

视界 mpv 集成从源码编译的 Omniphony 渲染引擎和 Dolby、DTS、IAMF 解码桥。播放兼容的 TrueHD Atmos、E-AC-3 Atmos、DTS:X 或 IAMF 音轨时，可将空间音频按扬声器布局渲染为多声道，在系统与设备支持时通过 HDMI 或 ASIO 输出。可以选择 5.1、7.1 或配置后的 7.1.4 等布局。

可在全景声渲染、mpv 原生解码和源码直通之间选择。使用功放直通时，兼容的原始音轨由功放解码。用播放器渲染时，可通过声场对象视图观察声音对象的位置。信息面板可以核对音轨、解码方式和输出设备。

入口　右键 → 音频 → 输出设置。播放时按 I 查看音轨与输出状态。

10　电视直播、节目单与回看

导入自备的 M3U、M3U8 或 TXT 频道列表，也可以添加订阅和单个直播地址。频道与台标来自用户导入的来源。频道墙支持按分组浏览、搜索、收藏和查看当前节目。导入时可应用频道过滤规则，订阅可分别设为自动更新或手动更新。同一频道有多条线路时，可打开线路面板检测，按本次出画结果选择可用线路。

遥控器默认用上下方向键换台，左方向键打开频道列表，右方向键打开节目单，确定键打开直播菜单。返回时先关闭面板，再回到刚看的频道位置。可选择返回频道墙时停止播放或继续播放，操作也可以自定义。

节目单支持从订阅自动提取 EPG 地址，也可设置 XML、XML.GZ 或按频道查询的接口。可左右切换日期，查看正在播、接下来播什么和之前的节目。在直播源提供回看、节目仍在回看期限内时，可从节目单回看已播节目，把当前节目从头播放，也可随时回到直播。

入口　按 T 打开电视直播。按 E 查看节目单，也可从播放页「频道」旁打开。电脑设置中心 → 电视直播用于管理来源、节目单与过滤规则。

11　音乐与手机遥控

音乐可按专辑和曲目浏览。打开专辑后可直接选择某一首开始播放，播放页显示封面、当前曲目和列表，并支持切歌、调整进度和返回专辑。有 LRC 或内嵌歌词时，还可以随歌曲进度查看歌词。文件夹浏览也适用于按目录整理的本地音乐。

在同一局域网内，用手机浏览器扫码或输入配对码，即可连接电脑。手机上可以浏览本地或 Emby 片库、看封面、选择影片或音乐、控制播放及发送遥控按键。已经配对的手机可在下次使用时重新连接。

入口　从海报墙进入音乐。桌面右上角的网络入口或「视界 MPV 手机遥控器」菜单可以打开配对页。

12　电脑设置中心、备份和诊断

电脑设置中心通过浏览器管理片库目录、Emby、直播订阅、节目单、字幕、片库整理和遥控操作。设置中心还可按用户设置管理刮削任务和文件整理规则。换电脑或重装时，可用「备份与恢复」导出设置，再按页面提示导入。

播放时按 I 打开中文信息面板，可查看分辨率、片源帧率、显示刷新率、实际视频输出、音轨格式和音频输出设备，以及缓存、丢帧和解码情况。杜比片源还可查看 Profile、增强层、内容映射和 L5 活动区域等资料，便于区分片源格式与实际显示输出。

「工具与诊断」提供杜比视界与显示端检测、CB1 模式支持检查和日志导出。反馈播放、片库或手机遥控问题时，可从此处导出相关播放器和后台服务日志。

常用快捷键

W　海报墙　　　　　　　　T　电视直播
O　打开文件　　　　　　　H　近期播放
A　音轨选择　　　　　　　J　字幕选择
I　信息面板　　　　　　　K　视界设置
F　全屏／窗口　　　　　　B　最小化
F3 搜索　　　　　　　　　空格　播放／暂停

以上为常用默认键位。播放、菜单和电视直播页面的方向键及确定键遵循各自的操作逻辑，可在「外观设计」中调整常用操作。
